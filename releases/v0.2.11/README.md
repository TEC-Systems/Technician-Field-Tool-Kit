# TEC Systems Field Toolkit 0.2.11

IP Scanner now sits immediately next to IP Shifter.

**To install manually:** Download `TEC-Systems-FieldToolkit-Install.zip`, extract it, run `TEC-Systems-FieldToolkit-Setup.exe`, and click **Install** or **Update**. If the toolkit is already running, first right-click its TEC notification-area icon and choose **Exit Toolkit**.

**To update from 0.2.10:** Once the v0.2.11 GitHub Release is published, click **Check Updates** in the running toolkit. It will verify the download, exit fully, and launch Setup.

The `portable/` folder contains the direct-run EXE for IT testing; it is not the installer. The installer is currently unsigned. `SHA256SUMS.txt` records the Setup EXE checksum.
