# TEC Systems Field Toolkit 0.3.35

## Changed

- IP Shifter now explains that a duplicate-IP check is limited when switching to a different subnet. This confirmation is expected and does not mean the change failed.
- Before changing a static adapter, IP Shifter prefers its configured IPv4 address when saving the restore point. This avoids treating transient addresses in Windows' live list as extra configured addresses.
- If an adapter truly has multiple configured static IPv4 addresses, the error lists them so the technician can review the adapter in Windows.

## Removed

- None. The restore-point safeguard remains in place for configurations the toolkit cannot reliably restore.
