# TEC Systems Field Toolkit 0.3.36

## Changed

- The toolkit opens within the usable Windows screen area and adjusts after display settings change.
- Header and bottom-bar controls reposition when the window is narrowed.
- Larger tabs and the Activity Report stay accessible on smaller screens through scrolling.
- The IP Scanner results keep a usable height when the toolkit window is shortened.

## Removed

- None. Existing toolkit features remain available.
